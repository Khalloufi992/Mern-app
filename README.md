# MERN REST API Application

A simple MERN stack application built with MongoDB, Express.js, React, and Node.js.

The backend provides a REST API for managing users, while the React frontend consumes the API and displays the stored users.

## Technologies Used

- MongoDB Atlas
- Express.js
- React
- Node.js
- Vite
- Mongoose
- REST API
- Render
- GitHub
